# Racket

Racket (Rack-it) is a small web app for managing and tracking hardware across
multiple machines — servers, desktops, NAS boxes, or anything else with parts
inside.

## Features

- Group hardware into **machines**.
- Track machine stats: build date, purchase date, location.
- Track part stats: category, manufacturer, model, serial number, warranty,
  purchase info, and guide URL.
- Vue 3 SPA compiled to static assets and embedded into the Go binary —
  one self-contained executable.
- SQLite database with type-safe queries generated by sqlc; goose migrations
  applied automatically on startup.

## Tech Stack

- Go 1.26
- [chi](https://github.com/go-chi/chi) router
- [charmbracelet/log](https://github.com/charmbracelet/log) for structured logging
- Vue 3 (Composition API + TypeScript), built with Vite, packages via pnpm
- SQLite (via `modernc.org/sqlite`, no CGO)
- sqlc + goose

## Getting Started

Requirements:

- [mise](https://mise.jdx.dev/)

Install dependencies and run:

```bash
mise install
mise run start
```

Then open <http://localhost:8080>.

For development with the Vite dev server (hot reload) alongside the Go server:

```bash
mise run dev
```

See all tasks:

```bash
mise tasks
```

## Project Layout

```
cmd/server/         Application entrypoint
frontend/           Vue SPA (built to frontend/dist, embedded in the binary)
frontend_embed.go   //go:embed of the built frontend
internal/
  db/               sqlc-generated code + queries
  handlers/         HTTP handlers (JSON API under /api/*)
migrations/         goose migration files
```

# Racket

Racket (Rack-it) is a small web app for managing and tracking hardware across
multiple machines — servers, desktops, NAS boxes, or anything else with parts
inside.

## Features

- Group hardware into **machines**.
- Track machine stats: build date, purchase date, location.
- Track part stats: category, manufacturer, model, serial number, warranty,
  purchase info, and guide URL.
- HTMX-powered UI with server-rendered HTML via Templ.
- SQLite database with type-safe queries generated by sqlc and migrations via
  goose.

## Tech Stack

- Go 1.26
- [chi](https://github.com/go-chi/chi) router
- [charmbracelet/log](https://github.com/charmbracelet/log) for structured logging
- HTMX + Templ
- SQLite (via `modernc.org/sqlite`)
- sqlc + goose

## Getting Started

Requirements:

- [mise](https://mise.jdx.dev/)

Install dependencies and run:

```bash
mise install
mise run start
```

Then open <http://localhost:8080>.

For development with auto-reload of templates:

```bash
mise run dev
```

See all tasks:

```bash
mise run help
```

## Project Layout

```
cmd/server/         Application entrypoint
internal/
  components/       Templ components and helpers
  db/               sqlc-generated code + queries
  handlers/         HTTP handlers
migrations/         goose migration files
static/             CSS and static assets
```

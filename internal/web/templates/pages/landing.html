What is Racket?

Racket (Rack-it) is a notebook for your hardware. Make an entry for each machine: server, desktop, NAS, whatever's humming in the corner. Then log the parts inside, so you never have to remember which stick of RAM is in which box.

Machines

One entry per box: build date, purchase date, and where it lives (the closet counts).

Parts

Model, serial number, warranty, purchase info, and a guide URL — the stuff you always need exactly once, at 11pm.

Easily self-hostable

One Go binary and a SQLite file — download it, run it, done. No database server or other moving pieces to set up.
